# Aktueller Kontext

## Fokus
Implementierung der Authentifizierung (Auth.js v5) und des Registrierungs-Flows inkl. Haushalts-Logik.

## Letzte Entscheidungen
- **Registrierung:** Nutzer können während der Registrierung entweder einen Haushalt erstellen (wird Admin) oder einem beitreten.
- **Auth.js v5:** Einsatz der Beta-Version für native Next.js 15+ Kompatibilität.
- **Design:** "Helles, kaltes Farbdesign" (Hellblau, kühles Grau, Weiß).
- **Security:** Bcrypt für Passwort-Hashing.

## Nächste Schritte
1. Installation der Abhängigkeiten (`next-auth@beta`, `bcrypt`).
2. Konfiguration von Auth.js (`src/auth.ts`, `middleware.ts`).
3. Erstellung der Server Actions für Registrierung und Login.
4. UI-Entwicklung: Login & Registrierung (Vanilla CSS Modules).

## Offene Fragen
- Maximale Länge des Einladungscodes für Haushalte.
- Design-Details für Fehler-Feedbacks (Toasts vs. Inline).
