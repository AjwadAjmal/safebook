# Tech Kontext

## Stack
- **Framework:** Next.js (React)
- **Styling:** Vanilla CSS (CSS Modules) - Mobile-Only Fokus.
- **Datenbank:** PostgreSQL (gehostet auf VPS).
- **ORM:** Drizzle ORM mit `drizzle-kit` für Migrationen.
- **Authentifizierung:** Auth.js (Username/Passwort-basiert, keine E-Mail).
- **Automatisierung:** n8n (via Webhooks für komplexe Logik wie Rücklagen).
- **Infrastruktur:** Eigener VPS für App, DB und n8n.

## Entwicklungs-Workflow
- **Lokal:** `npm run dev` auf der Entwickler-Maschine.
- **Datenbank-Anbindung:** SSH-Tunnel zum VPS (Port 5432), um direkt mit der Produktions-DB-Struktur (aber vorsichtig!) zu arbeiten.
- **Migrationen:** Definition in TypeScript via Drizzle, Push zum VPS via `drizzle-kit`.
- **Deployment:** Git-basiert auf den VPS.

## Backup-Strategie
- Automatisierte Cronjobs auf dem VPS erstellen täglich Datenbank-Dumps.
- Diese Dumps werden verschlüsselt auf ein lokales Laufwerk übertragen.

## Laufzeit-Umgebung
- Node.js Runtime auf dem VPS.
- PostgreSQL Instanz.
- n8n Instanz (Docker-basiert oder direkt).
